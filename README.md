# Unbeatable Tic-Tac-Toe AI

## Overview
An interactive, AI-powered Tic-Tac-Toe game developed in Python. The computer opponent uses the Minimax algorithm, making it mathematically impossible to beat. 

## Technologies Used
* **Language:** Python
* **Algorithm:** Minimax
* **GUI:** Tkinter

## Key Features
* Unbeatable AI utilizing the Minimax decision-making algorithm.
* User-friendly Graphical User Interface (GUI) built with Tkinter.
* Real-time game state evaluation (win, lose, tie).
